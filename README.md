# BaseWars

A **Garry's Mod** base-building / combat gamemode. Players earn money, build and
defend fortified bases, run illicit economies (money printers, drug labs, meth,
stills, weed), and raid each other with a large arsenal of weapons and
explosives. This gamemode is based on a older build from lmaollama.
It has been upgraded from GMOD 12 to 13 that makes it playable.

- **Base gamemode:** `sandbox`
- **Version:** 1.9
- **Map prefix:** `basewars_` (the menu lists maps starting with `basewars_`)
- **Original author:** Rickdark / HLTV Proxy — **developed by** LlamaLords.

---

## Features

- **Base building & prop protection** — claim props and structures; only the
  owner (and admins) can touch them.
- **Economy** — a full money system with tiered **money printers** (bronze →
  silver → gold → platinum → diamond → nuclear and more), plus banks/vaults.
- **Illegal industry** — **drug labs, meth labs, stills, and weed plants** that
  produce income over time and can blow up if neglected.
- **Structures** — buyable defensive structures (turrets, dispensers, lamps,
  player spawn, radar towers, power plants) with owner-based protection.
- **Weapons** — 50+ SWEPs built on the MadCow SWEP base, plus grenades, C4, door
  charges, and a `worldslayer`/`bigbomb` for raiding.
- **Drugs system** — consumable effects (regen, antidote, painkiller, reflect,
  adrenaline, and more).
- **Self-contained content** — models, materials, and sounds ship in `content/`
  and are auto-registered for client download.

---

## Requirements

- A **Garry's Mod dedicated server** (srcds).
- **FPP (Falco's Prop Protection)** installed as a **standalone addon** — this
  gamemode relies on it for prop/structure ownership. It is *not* bundled.
- Counter-Strike: Source content is recommended for some models/sounds.
